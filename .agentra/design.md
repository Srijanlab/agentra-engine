- Operator attribution: `server/audit.py` (`actor_for`/`audit_log`) resolves the caller (Firebase email from `request.state.user_email`, `verify-token` from `request.state.actor`, `loop` for `/internal/*`, else `anonymous`) and threads it through `_server_log` -> `registry.record_signal(..., actor=)`, so the signals feed shows who triggered pause/resume, app register/update/remove, llm-backend changes, triggers, promotes and human answers.
- Window-free per-app queries: schedule status, stale-run reconciliation and loop lookups use app-scoped, paginated/unbounded reads (`list_app_runs(limit=None)`, `list_jobs(limit=None)`, `list_loops_by_status`) instead of the global fixed-size newest-N feed, so one app's runs/jobs can't be hidden by other apps' traffic. `_stale_run_candidates` = newest-200 global window plus every queued/running run per registered app.
- Shared app-config write path: `server/routes/app_config.py::_apply_app_config` is the single place that applies objective + `EnvironmentConfig` fields to a coordination repo and commits `.agentra/` (skipped in cloud mode), reused by app registration (new and existing repo) and update.
- Durable signals feed appends atomically (`list_append` `update_item`) with a conditional-trim retry loop instead of a read-modify-write, so concurrent events don't drop each other.
- Per-job heartbeat lease: a claimed job is judged stale only by its own `heartbeat_at`; poison jobs (max attempts) are terminal-failed and raise a human gate.
