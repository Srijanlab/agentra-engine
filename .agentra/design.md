- Engine = state authority, loop = execution — a hard split. Trigger endpoints only `registry.enqueue_job({cycle|promote|prod_debug|human_resume})`; agentra-loop drains the queue and reports back. The engine carries no `claude-agent-sdk` and no docker/deploy code.
- One RPC contract. `POST /internal/rpc` gated by `AGENTRA_INTERNAL_TOKEN` (+ optional Vercel-header IP allowlist), restricted to the `_REGISTRY_METHODS` / `_MEMORY_METHODS` frozensets, is the entire state surface the loop may touch. Credential-holding side doors are separate token-gated endpoints (`/internal/git-token`, `/internal/slack/message`, `/internal/runs/{id}/log`).
- Dual-path persistence. Every registry/memory write is `if core._ddb: <DynamoDB> else: <local JSON under AGENTRA_HOME>`. `cloud_mode()` gates all checkout-dependent behavior.
- Per-job heartbeat leases (changed): `_requeue_stale_claims` now evaluates each claimed job by its own `heartbeat_at`, replacing the earlier app-wide max-heartbeat ceiling, so one live job no longer shields other stale claimed jobs of the same app from reclaim.
- Durable signals feed: `GET /signals` is backed by `registry/signals.py` (dual-path: single DynamoDB `system` item `key="signals"` or local `signals.json`), a bounded ring of the newest 200 events. DynamoDB writes are now an atomic `list_append` plus a size-conditional trim with bounded retries (no more lost-update read-modify-write). `server.utils._server_log` writes to it alongside the logger and swallows storage errors.
- Hardened auth edges: the Firebase gate requires `email_verified` and only honours `?access_token=` on the SSE logs path; `/trigger/queue` is fail-closed for Pub/Sub OIDC (audience AND service-account email both required) and returns the shared 401 body with a static hint via a `QueueAuthError` exception handler instead of `HTTPException`.
- Idempotent human answers: `dispatch_human_answer` no-ops (ack only) if the issue is no longer pending, enqueues the resume job before recording the answer, and on enqueue failure marks the run failed so the API returns 503 and the answer is not consumed.
- Unified 401 shape (issue #83): the Firebase gate, verify-token gate, and queue gate all build the `{detail, error: "authentication_required", hint}` body from `verify_token.unauthenticated_body()`, and the hint never leaks secret values.
