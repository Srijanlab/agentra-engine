- **Deterministic guardrails over prompt instructions**: circuit breakers (`MAX_CONSECUTIVE_TOOL_FAILURES`, stagnation window), "tests must pass before deploy", "pre-prod verified before promote", and push-failure hard-stops are plain Python booleans in `OrchestratorSession`, not system-prompt rules.
- **Two orchestration modes on purpose**: `orchestrator.run_cycle` (fixed understand->discover->implement->test->deploy pipeline, `--fixed-pipeline`) and the default `agents/brain.run_autonomous_cycle` (LLM picks from tool-wrapped agents). Deterministic fallback always exists.
- **State split by ownership**: engine's cross-app bookkeeping -> Firestore/DynamoDB/local-JSON (`AGENTRA_HOME`); a target repo's product knowledge (bugs, features, objective, env config) -> that repo's own GitHub Issues/Projects/Actions Variables with no local mirror.
- **Layered safety**: Docker sandbox (non-root, read-only FS, `--cap-drop ALL`) is primary; `agents/safety.py` regex PreToolUse hook is defense-in-depth (chosen over the SDK's `can_use_tool` because that is bypassed under `bypassPermissions`).
- **Credential centralization**: the loop never holds Firestore creds, the GitHub App key, or `SLACK_BOT_TOKEN` — it calls `/internal/rpc`, `/git-token`, `/slack/message`. Method whitelists (`_REGISTRY_METHODS`/`_MEMORY_METHODS`) are the actual RPC contract.
- **Keyless cloud auth**: Vercel per-request OIDC JWT -> GCP Workload Identity Federation for Firestore (survives `disableServiceAccountKeyCreation`); DynamoDB uses static IAM keys because AssumeRoleWithWebIdentity failed for that account.
- **Spec freshness gate**: `codebase.sync_spec` serves the committed `.agentra/architecture.md` at zero LLM cost when `git HEAD == state.json.indexed_sha`, else does a bounded `mode="delta"` update; specs are committed to the pre-prod branch by `persist_repo_specs` before any feature branch forks, so they never appear in a feature PR.
- **Failure taxonomy**: regex lists in `memory/core.py` split failures into transient/quota (retry), unfixable-by-agentra (file & stop), and login-required (file blocking bug + Slack + auto-clear on next good run).
- **Observability**: one Langfuse trace per cycle, one `generation` per agent turn and per orchestrator reasoning turn; all Langfuse calls are try/except no-ops without credentials.
- **Mixin/package composition** to respect the 500-line rule: `Memory` is 5 mixins, `registry`/`agents.brain` are packages with re-exporting `__init__.py`.
