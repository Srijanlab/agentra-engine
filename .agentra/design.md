- **Engine = state authority, loop = execution — a hard split.** Trigger endpoints only `registry.enqueue_job({cycle|promote|prod_debug|human_resume})`; agentra-loop drains the queue and reports back. The engine carries no `claude-agent-sdk` and no docker/deploy code.
- **One RPC contract.** `POST /internal/rpc` gated by `AGENTRA_INTERNAL_TOKEN` (+ optional Vercel-header IP allowlist), restricted to the `_REGISTRY_METHODS` / `_MEMORY_METHODS` frozensets, is the entire state surface the loop may touch. Credential-holding side doors are separate token-gated endpoints (`/internal/git-token`, `/internal/slack/message`, `/internal/runs/{id}/log`) so the loop never holds the GitHub App key or Slack token.
- **Dual-path persistence.** Every registry/memory write is `if core._ddb: <DynamoDB> else: <local JSON under AGENTRA_HOME>`. DynamoDB (static `AGENTRA_AWS_*` IAM keys, prefixed to dodge Vercel's reserved bare `AWS_*`) backs prod; local JSON serves the CLI, tests, and the loop's own process. `cloud_mode()` gates all checkout-dependent behavior.
- **Job queue design.** DynamoDB table with a `by-status` GSI, CAS `pending->claimed` claiming, stale-claim requeue after 1h, `dedup_key` enforcing one open job per app per kind, and native TTL (`expires_at`) on terminal jobs.
- **State split by ownership.** Engine bookkeeping -> DynamoDB / local JSON; a target repo's product knowledge (bugs, features, objective) -> that repo's GitHub Issues/Projects; deploy-pipeline config -> that repo's GitHub Actions Variables (`environments.py`). No local mirror.
- **Multi-repo apps.** `RepoSpec` with exactly one `role="coordination"`; `Memory` always binds to the coordination repo; a legacy single-repo app is one spec that is both coordination and code.
- **Failure taxonomy is regex lists in `memory/core.py`.** Failures split into transient/quota (retry — includes rate/usage/weekly-limit, overloaded, and 5xx/gateway errors per issue #18), unfixable-by-agentra (unauthorized / permission denied — file & stop), and login-required (issue #42 — Claude Code CLI not authenticated). Regression tests lock in the exact wording.
- **Composition for the 500-line rule.** `Memory` is 5 mixins; `registry` is a package whose `__init__` swaps in a proxy module delegating selected names to `core`.
- **Graceful degradation everywhere.** `/health` never fails; DynamoDB init returns `None` instead of raising; Langfuse calls are try/except no-ops; `api/index.py` serves a diagnostic fallback app if `agentra.server` fails to import.
- **Held, not half-built.** Chat-turn and standup *generation* return 503 pending their move to the loop, rather than shipping a broken cloud path.
- **Layered auth.** Dashboard = Firebase ID token + `AGENTRA_ALLOWED_EMAILS` (open when `FIREBASE_PROJECT_ID` unset); `/internal/*` = internal bearer token; `/trigger/alarm` = Basic-auth password; `/trigger/cron` = internal token or `CRON_SECRET`.
- **Polling over webhooks.** No inbound Slack/GitHub webhook; the loop's drain loop hits `GET /trigger/cron` (~5 min) to reconcile stale runs, poll `need_human` issue comments for answers, enqueue due scheduled cycles, and escalate timed-out human-input loops.
