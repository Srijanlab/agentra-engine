This IS agentra's own source code -- the system managing this repo is the same system running in it (self-hosted/dogfooding). Deployment is NOT Vercel or Firebase -- it's a bespoke pipeline: Dockerfile (multi-stage: builds agentra/web/ React app via Node, then the Python package) -> Cloud Build (deploy/gcp/cloudbuild.yaml) -> Artifact Registry -> `gcloud run services update` on the agentra-orchestrator Cloud Run service in project agentra-prod. See docs/deployment.md for the full runbook. The existing deploy_pre_prod/promote_prod tools only know Vercel/Firebase CLIs, so they will correctly report 'skipped' for this repo -- deploying a real change here currently requires a human running the gcloud commands in docs/deployment.md, not an autonomous deploy. Architecture docs: vision.md (product vision), CONTAINER.md (container hardening), tasks.md (completed task history with commit SHAs).
